Ты работаешь по файлу `ROADMAP.md` в корне проекта. Выполни строго следующее:

1. **Прочитай ВЕСЬ `ROADMAP.md` полностью** — от начала до конца.
2. **Определи текущий этап** — первый невыполненный пункт `[ ]` (сверху вниз).
3. **Работай строго по roadmap, по порядку**, не пропуская этапы и пункты.
4. **Продолжай выполнять задачи** текущего этапа до тех пор, пока пользователь не напишет `/stop`.

## Правила работы
- Не пропускай пункты: выполняй их в том порядке, в котором они идут в roadmap.
- Сверяйся с `TZ.md` (техническое задание) — там детали требований по каждому этапу.
- После выполнения каждого пункта продолжай к следующему без остановки (кроме случаев, когда нужно уточнение у пользователя).
- **НЕ отмечай** пункты как `[x]` сейчас — отметка выполненных пунктов происходит только по команде `/stop`.

## ⚠️ Правило безопасности
- URL бэкенда используется **ТОЛЬКО** через `import.meta.env.VITE_API_URL` из `.env`.
- Реальный адрес бэкенда **не пишется** нигде: ни в коде, ни в README, ни в комментариях, ни в `ROADMAP.md`, ни в `TZ.md`.
- `.env` должен быть в `.gitignore`; `.env.example` — с пустым placeholder.

Начни прямо сейчас: прочитай roadmap, сообщи какой этап и пункт ты берёшь в работу, и приступай.
